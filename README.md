# Naeem — Personal Portfolio

A personal portfolio website built to present my learning journey, technical interests, selected projects, and ways to connect.

The site uses a dark space-inspired visual style with neon cyan, violet, and blue accents, motion effects, and 3D elements.

## Overview

- Personal introduction and profile
- Technical skills and tools
- Selected projects with links
- Responsive navigation and footer
- Animated space background and visual effects
- Search and social-sharing metadata

## Technology

- **Next.js** — application framework
- **React** — user interface
- **TypeScript** — typed application code
- **Tailwind CSS** — styling
- **Three.js / React Three Fiber** — 3D visuals
- **Framer Motion** — interface animations

## Getting Started

### Requirements

- Node.js (LTS recommended)
- npm
- Git

### Install

```bash
git clone https://github.com/nansari7287-sys/Naeem...-portfolio.git
cd Naeem...-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production build

```bash
npm run build
npm run start
```

## Project Structure

```text
app/                 Next.js routes, layout, and global styles
components/main/     Main portfolio sections
components/sub/      Reusable interface components
config/              Site metadata and configuration
constants/           Portfolio content and navigation data
lib/                 Shared utilities and animation helpers
public/              Images, icons, and visual assets
```

## Customization

- Update personal details and project entries in `constants/index.ts`.
- Update SEO and social preview metadata in `config/index.ts` and `app/layout.tsx`.
- Update global colors and shared styles in `app/globals.css`.
- Add or replace images and videos in `public/`.

Keep project descriptions accurate: list only tools you have used and work you can demonstrate. Do not publish private keys, access tokens, passwords, or other secrets in this repository.

## Deployment

This project can be deployed to a platform that supports Next.js, such as [Vercel](https://vercel.com/). Connect the GitHub repository, configure any required environment variables, and deploy the selected branch.
